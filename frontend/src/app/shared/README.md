# Shared Module

## Overview
Reusable UI primitives, formatting pipes, input directives, and standard modal dialogs shared across all feature and layout modules.

## Subdirectories & Boundaries
- Shared Components: [./components/README.md](./components/README.md) - Reusable UI widgets including confirmation dialogs, margin chips, currency inputs, and pricing result cards.
- Shared Pipes: [./pipes/README.md](./pipes/README.md) - Template pipes for BRL currency and percentage formatting.
